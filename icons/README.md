# Extension Icons

This directory contains the extension icons in different sizes.

## Required Sizes

- `icon-16.png` - 16x16px (browser toolbar)
- `icon-48.png` - 48x48px (extensions page)
- `icon-128.png` - 128x128px (Chrome Web Store)

## Design Guidelines

**Visual Identity:**
- Simple, recognizable design
- Related to writing/feedback (pen, notebook, speech bubble, margin notes)
- Clean, professional look
- Works well at small sizes (16x16)

**Color Palette Suggestion:**
- Primary: Purple/Blue gradient (#667eea to #764ba2)
- Accent: White or light colors for contrast

**Concept Ideas:**
- Speech bubble with pen icon
- Notebook with margin annotations
- Stylized "MM" letters
- Quill or fountain pen
- Page with sidebar illustration

## Temporary Solution

Until proper icons are created, you can use:
- A solid color square (any color)
- Screenshot of 📝 emoji
- Simple text "MM" on colored background

The extension will still work without fancy icons during development.
